# DatioLabs: Especificación de Interfaz de Usuario (UI)

La interfaz se construye sobre Tauri utilizando rigurosamente HTML semántico, Tailwind CSS y Vanilla JS. Obedece el principio de "Inteligencia Aumentada, Carga Cero", priorizando el rigor institucional sobre el ruido visual.

## Tokens de Diseño (Configuración de Tailwind)
- `surface` (`#F8FAFC`): Fondo estructural que estabiliza el contraste general del Dashboard.
- `dark` (`#001F5B`): Dominante en tipografía, botones de acción estándar y encabezados. Mantiene elegancia.
- `accent` (`#0038A8`): Color para micro-interacciones (estados hover, anillos de enfoque).
- `secondary` (`#F8D02E`): Atractor visual restringido a interacciones de alta prioridad analítica.
- `danger` (`#C60C15`): Exclusivo para advertencias, notificaciones de riesgo o acciones destructivas.
- `success` (`#00823B`): Confirmación determinista y validación de estados correctos.
- `muted` (`#A6A6A6`): Texto auxiliar, sombras y estados inactivos.

## Indicadores Clave de Rendimiento (KPIs)
El Dashboard se enfoca en métricas ortogonales directas:
1. **Volumen Bruto**: Tracción absoluta de capital inyectado.
2. **Flujo Transaccional**: Densidad física (conteo directo de eventos).
3. **Eficiencia Vectorial**: Nivel de participación activa del catálogo contra el inventario inerte.
4. **Mapa de Calor Dimensional**: Distribución espacio-temporal de la carga analítica.
